# Graphite 1.24.0

Оглавление больше не выкидывает из режима чтения: клик по разделу просто прокручивает статью. Обновление прилетит само (`1.24.0 > 1.23.0`).

## Чтение
- В режиме чтения клик по пункту оглавления прыгает к заголовку.
- Режим правки по-прежнему ставит курсор на эту строку.

Полная история деплоев — в `CHANGELOG.md`.
