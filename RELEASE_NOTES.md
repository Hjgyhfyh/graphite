# Graphite 1.23.0

Конвейер из поиска: не только входящие. Обновление прилетит само (`1.23.0 > 1.22.0`).

## Поиск
- Фильтр `status:` даёт кнопки следующего шага: проработка → план → в работе → готово.
- Лёд — Shift+Enter; со льда Ctrl+Enter размораживает в проработку.
- Пустые колонки — отдельные тексты, не общее «ничего не найдено».

Полная история деплоев — в `CHANGELOG.md`.
