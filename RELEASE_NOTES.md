# Graphite 1.18.0

Имя заметки, написанное без скобок, больше не пропадает: такие места видны во вкладке бэклинков. Обновление прилетит само (`1.18.0 > 1.17.0`).

## Бэклинки
- Секция «Упоминания без ссылки»: поиск по названию текущей заметки, без уже связанных входящими `[[ссылками]]`.
- Клик открывает заметку; под названием — сниппет, где встретилось имя.
- Короткое или шаблонное название («Новая заметка») не ищется, чтобы не засорять список.

Полная история деплоев — в `CHANGELOG.md`.
