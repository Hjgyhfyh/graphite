# Graphite 1.5.0

Память поиска поверх 1.4.0. Обновление прилетит само (`1.5.0 > 1.4.0`).

## Поиск
- Пустая панель поиска показывает **недавние запросы** и **недавно открытые** заметки этого хранилища.
- Клик по запросу подставляет его снова; крестик убирает из истории.
- Запрос запоминается, если вы открыли результат или сделали паузу ~1 с на готовой выдаче.

## Палитра
- Ctrl+K без текста: блок «Недавние» — заметки, которые вы реально открывали. Если истории мало, добивается свежими с диска.

Полная история деплоев — в `CHANGELOG.md`.
