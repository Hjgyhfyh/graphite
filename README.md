# Graphite

Локальный кабинет для заметок и планов — обычные Markdown-файлы в вашей папке, без облака и подписок.

## Установка

Скачайте установщик из [последнего релиза](https://github.com/Hjgyhfyh/graphite/releases/latest) и запустите его.

## Обновления

Приложение обновляется само через GitHub Releases: когда выходит новая версия, внутри появляется карточка «Доступно обновление» — нажмите «Обновить», и новая версия скачается, проверится по подписи и установится.
